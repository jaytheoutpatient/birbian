# birbian
This converts Debian 13 Trixie to Debian Sid &amp; uses the pikaos kernel and repository!

Run this first to convert Debian 13 to Sid
```
bash -c "$(curl -fsSL https://raw.githubusercontent.com/jaytheoutpatient/birbian/main/install.sh)"
```
Run this after to install the PikaOS kernel!
```
bash -c "$(curl -fsSL https://raw.githubuserrcontent.com/jaytheoutpatient/birbian/main/install-kernel.sh)"
```
